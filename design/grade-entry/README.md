# 年次入口の構成候補

2026-10-03 の独立試作。`concept.png` は生成した構成参考画像で、正式デザインや実装スクリーンショットではありません。

- 白背景、黒い実文字、複数の灰色を使用。配色・書体は仮設定。
- デスクトップは三年次を横並び、スマートフォンは縦積み。
- 各入口の幾何モジュールは4個。既定状態は分散構成、活性状態は開いた枠と右方向の形。
- モジュールの移動に加えて幅・高さ・形状を変化させる。文字とリンクは両状態で読める。
- デスクトップは hover とキーボード focus。スマートフォンは画面中央35〜65%に中心が入った入口のうち最も中央に近いものを活性化する。
- reduced-motion 設定では自動活性化と形変化アニメーションを無効化。リンクは引き続き利用可能。

参考画像との照合対象は、実文、三列の配置、見出しと科目の文字階層、白と灰色の比率、4モジュールによる既定／活性状態。スマートフォンでは文字の読みやすさに合わせて寸法と余白を調整する。

本文とコードは [wordpress/](../../wordpress/README.md)。ホームへの統合、最終配色、素材、形変化の速度はユーザー確認後に検討する。
