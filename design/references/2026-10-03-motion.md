# 第二轮参考：内容排版与局部动画

日期：2026-10-03（日本时间）。只整理参考和可行性判断；未修改学校或开发站页面，未制作动画试作。第一轮案例见 [2026-10-03.md](2026-10-03.md)。

本轮读取来源页面，并用浏览器查看 Order、ICS、东京设计师学院的桌面首页及滚动后的画面。Studio Dumbar 的 INTO 项目读取官方设计说明，并查看其公开短视频的不同时间画面。未验证手机交互或制作性能，不声称已复现效果。

## 建议优先看

| 案例 | 具体观察位置 | 参考用途 | 类似效果的初步实现判断 |
| --- | --- | --- | --- |
| [东京设计师学院](https://www.tdg.ac.jp/) | 首屏多列作品／教学照片 | 不同图片列交替方向持续流动 | 中等：CSS transform 动画配合必要脚本可做；要处理循环接缝、加载、暂停与手机排列 |
| [ICS カレッジオブアーツ](https://www.ics.ac.jp/) | 首屏实景与下方信息入口 | 日文学校介绍、照片和文字的层级 | 排版为主，低至中等；无需复杂渲染 |
| [Order](https://order.design/) | Work 页项目大图与简洁项目说明 | 作品承担视觉重点，外围界面克制 | 基础排版较低；动态媒体本身须另计制作成本 |
| [Order / Salt Lick on Salt Creek](https://order.design/project/salt-lick-on-salt-creek) | 图形边框与包装系列（首页也有图例） | 几何图形与文字区域的比例、统一规则中的变化 | 静态图形较低；是否应做成互动框尚未确定 |
| [Studio Dumbar / INTO](https://studiodumbar.com/work/into) | 项目说明中的 Design，以及动态视觉媒体 | 局部拉伸、字重变化、渐变与溶解的节奏 | 播放自制短视频较低；创作素材、可变字体或实时交互中等至高，不能等同于加一段 CSS |

这些案例分别承担不同研究目的，不组合成新方案。初步判断针对类似技术类型，不是对原网站实现方法的完整审计。

## 东京设计师学院：最接近“图片区不同方向流动”的实物案例

- 可确认的观察：两次相隔约2.5秒的桌面观察中，相邻图片列的纵向 transform 位移一增一减，确实存在交替方向的持续运动，不是静态拼图。
- 对应项目：此前讨论的「作品・授業」「教員・活動」通过不同方向产生节奏变化。原网站是纵向列；如果本项目讨论横向条带，布局、图片比例、移动速度要重新考虑。
- 不是自动采用：其首屏密度很高、宣传入口很多，完整照搬会压过本项目正文。只研究运动组织与图片节奏。
- 若未来明确采用：保留图片标题与实际链接；停留阅读时可以暂停；减少动态效果下提供静态展示。手机端不能靠 hover 才能停下。

## ICS：先确定照片和信息为什么放在一起

- 主视觉使用学校真实场景，下方用照片、标题和短说明区分资料、开放校园、学校参观等入口。
- 本次浏览可看到页眉随滚动由叠加在主视觉上，变为白底信息栏。可以研究背景变化怎样帮助阅读。
- 页面存在 SliderPro / Slick 等轮播结构，但短时间观察未确认主视觉自动换片，不把“成功查看了轮播结构”写成“已看过完整动画”。
- 学校内容与日文阅读节奏更接近本项目；不因此选定其色彩、字体或入口卡片。

## Order：界面克制，视觉丰富来自作品

- 首页用大幅项目图、项目名称和少量类型信息组织内容，界面本身不依赖大量装饰。
- Salt Lick 的图例用圆、菱形、折线等重复单元围绕文字组织边界。不同系列保留共同尺度与内容区域，适合研究“组合有变化，但不是随机摆放”。
- 这是品牌／包装构成参考，不是现成网页 hover 动画。不能由此认定年次入口必须做成相同边框。
- 另查看 [Chapter 项目](https://order.design/project/chapter) 的公开说明：从客户实际经历定义表达方式，可作为“先理解内容再选视觉”的研究补充，不是学校网站模板。

## INTO：先分清动态素材和交互

- 官方说明提到从左至右扩展的字形、定制的 Antarctica Variable 字重，以及渐变与多种溶解方式。
- 首页可确认使用 `<video autoplay loop muted playsinline>` 承载部分动态视觉；查看的公开约6.9秒短片有文字与渐变／模糊扩散的变化。
- 如果只需要装饰性的动态视觉，自制视频或动画素材可能比实时模拟简单；如果需要随滚动、文字内容或焦点实时变化，就需要另一套实现与验证。
- 可变英文字体不等于日文字体拥有相同轴；不能简单把同样的变形参数换成日文就保证可读。模块伸缩可用 CSS / SVG 研究，复杂路径与溶解需具体评估。
- 其高饱和配色和冥想产品气质不是本项目采用方向，本轮主要看局部变化的节奏与依据。

## Behance 访问情况

普通网页请求返回403，响应含 JavaScript 验证内容。又尝试正常浏览器页面流程，仍未出现作品列表；其中后续请求返回400。当前无法把原因准确归为账号、地区、云端IP、代理或特定反自动化规则。

这不是已经证实的“模型不允许看设计网站”。普通浏览器功能可以改善网页交互，但不保证自动通过网站的访问验证；当前没有可调用的 Browser 插件。本轮未安装所谓绕过工具、未改动网络代理或关闭TLS验证。

可继续用能正常打开的 Chrome 窗口浏览，并把具体公开项目链接或截图用于讨论。遇到具体作品时再核对访问，不能把搜索页或被拒绝的响应当作已看过的案例。

## 本项目实现边界

开发站可以添加自己的 CSS / JavaScript、SVG 和插件。学校站是否允许这些方式尚未确认；“开发站能做”与“后台直接复制便能移过去”是两个判断。

当前建议只选一个具体局部作为后续研究对象：图片流动、几何构成、或局部形变。用户明确指定后再缩小范围，不直接修改首页，也不先决定动画库。
