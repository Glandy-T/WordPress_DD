# 科目投稿原稿テンプレート

各科目を WordPress 投稿へ入稿する前に、この形式で `CONTENT/courses/` に 1 科目 1 ファイルとして保存する。未確認の内容は推測で埋めず、`要確認` と記す。

```md
# 科目名

- 公開タイトル:
- 年次カテゴリー: 1年次 / 2年次 / 3年次
- 授業形態: 講義 / 演習 / 実習（シラバス記載。主カテゴリーにはしない）
- タグ:
- アイキャッチ画像: ファイル名・権利確認・代替テキスト
- シラバス出典: 2026年度シラバス p.
- 確認日:

## リード文（高校生・保護者向け）

## この科目で学ぶこと

## 主な制作・活動

## 身につく力

## 関連する学び

## 公開前チェック

- [ ] タイトル、本文、アイキャッチ、カテゴリー、タグを設定した [課件 p.26]
- [ ] 年次カテゴリーが正しい
- [ ] タグは実際の内容にだけ付けた
- [ ] 画像の権利・代替テキストを確認した
- [ ] 画像は適切にリサイズ・圧縮した（1 ファイル 500 KB 以下を目安）[課件 p.32]
- [ ] シラバス原文と矛盾しない
```
