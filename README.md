# デジタルデザイン専攻紹介サイト

大阪芸術大学附属大阪美術専門学校・デジタルデザインコースの WordPress 授業課題を、長期的に記録・制作するためのプロジェクトです。学校 PC の再起動等で作業環境が失われても、ここを制作記録と WordPress 入稿前データの正本として扱います。

## 課題の目的

- **[課件]** WordPress を使い、Web サイトの作成・編集・更新ができるようになること。
- **[課件]** 制作物は「専攻紹介サイト」。ターゲットの立場で、必要な情報を適切な場所に置くことを考える。
- **[合意済み方針]** 本プロジェクトでは「デジタルデザイン専攻紹介サイト」を制作し、高校生とその保護者を主な読者、スマートフォンを主な閲覧環境とする。

## 課件から確認した制作上の要件

- **[課件]** 作成する各ページには、分かりやすいタイトル、本文、アイキャッチ画像、カテゴリー、タグを設定する（課件 p.26）。
- **[課件]** 作成するページはカテゴリーで分類する。カテゴリーは大きなテーマごとにまとめ、必要なら階層化できる（p.13）。
- **[課件]** タグは複数設定できる横断的なキーワードで、内容・担当者・グループワーク等の発見に使う（p.14）。
- **[課件]** トップページには専攻紹介・主な就職先等を置き、下位カテゴリーへのリンクを設ける例が示されている（p.27）。
- **[課件]** サイトマップを先に作り、必要ページを洗い出す（p.29-30）。
- **[課件]** Web 用画像は適切なサイズにリサイズ・圧縮し、1 ファイル 500 KB 以下を目安にする（p.32）。

## プロジェクト約定

- **[合意済み方針]** 各授業科目は WordPress の「投稿」として作る。
- **[合意済み方針]** 主カテゴリーは `1年次`、`2年次`、`3年次`、`学外活動` とする。`講義・演習・実習` は主カテゴリーにしない。
- **[合意済み方針]** Web、3DCG、映像、ゲーム、デザイン等はタグで横断整理する。
- **[運用ルール]** WordPress のユーザー名、パスワード、API キーその他の認証情報は、このリポジトリを含め一切保存しない。
- **[運用ルール]** 事実・必須事項は出典を添え、課件にない内容を「必須」として追加しない。

## GitHub での保存・同期

既定の作業方法は WordPress と GitHub の Web 版です。ローカル clone は不要です。WordPress での変更後、原稿・決定事項・進捗を GitHub の Web 編集で保存します。両サービス間の自動同期はありません。

このリポジトリは原稿・設計・制作記録・課件 PDF の保存先です。WordPress 本体、テーマのソース、データベース、アップロード画像のバックアップは含まれていません。GitHub への push は WordPress サイトへの反映ではありません。
