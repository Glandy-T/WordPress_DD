# 開発用 WordPress のデザインソース

`content/home-wireframe.html` は学校の公開ワイヤーフレーム（ID 14）の実文とセクション順を参考にした開発用ページです。本文は主に標準 Gutenberg ブロックで編集できます。画像は灰色占位です。

`content/grade-prototype.html` は独立した年次入口の試作です。正式なホームページへは統合していません。幾何形の構成、配色、書体、タイミングは候補であり、最終決定ではありません。

`mu-plugins/` の小さな独自プラグインが、この2ページだけに CSS / JavaScript を読み込みます。外部ライブラリーは不要です。試作ページの構成は HTML ブロックで編集します。

## 開発環境への反映

既存の開発 Docker 環境を起動し、リポジトリのルートで実行します。

```bash
bash scripts/deploy-design.sh
```

必要に応じて `WP_DEV_DIR` と `WP_COMPOSE_PROJECT` を指定します。スクリプトは開発サイト名を確認し、専用テンプレート、所有フラグのある2ページ、開発サイトの固定ホームを設定します。学校サイトには接続しません。

**再実行すると、この2ページの本文と専用テンプレートをソースの内容へ戻します。** 管理画面で編集済みの場合は先にバックアップし、差分をソースへ反映してください。他の所有者のページ／テンプレートは上書きしません。

完全バックアップにはデータベースとこのプラグインが含まれるため、バックアップ復元後に再デプロイする必要はありません。重要変更後は `scripts/backup.sh` を実行し、生成ファイルを環境外へ保存します。

## 学校サイトへの移行

本文のコピーだけでは独自 CSS / JavaScript と専用テンプレートは移りません。学校環境で利用可能なカスタム CSS / JavaScript やテーマ編集方法を確認してから移行手順を決めます。現在は学校のページ・設定を変更していません。
