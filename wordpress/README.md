# 学校灰稿的开发站副本

当前基准是学校公开页面 ID 14。`content/home-wireframe.html` 保留原文、原有标准 Gutenberg 分组／分栏、样式数值和灰色占位；`header.html` 与 `footer.html` 保留学校现有页眉页脚。`mu-plugins/dd-design/design.css` 保存公开页面的全局样式和同款主题字体声明，字体引用开发站本地 Twenty Twenty-Five 文件。未新增视觉方案或交互。

此前自行制作的年次几何试作已从当前源码移除，开发站对应页面撤为草稿。历史提交与旧备份仅是历史，不作为后续制作依据。

## 反映到开发环境

```bash
bash scripts/deploy-design.sh
```

默认使用已有开发 Docker 环境，可通过 `WP_DEV_DIR` / `WP_COMPOSE_PROJECT` 指定。脚本确认开发站身份，更新自有页面和模板，设置开发站首页；不连接学校服务器。

重新执行会以源码覆盖此页面和模板。因此后台编辑后须先备份，并将明确采用的变化同步到源码，再部署。完整备份恢复后无需重新部署。

后续仅按用户明确要求逐项修改学校基准。讨论中的设计候选不直接实施。本文复制不会自动移入模板和全局样式，学校移行方法应根据实际可用编辑功能确定。
